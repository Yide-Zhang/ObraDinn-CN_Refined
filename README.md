# Obra Dinn 中文精修补丁

《Return of the Obra Dinn》（奥伯拉丁的回归）的**中文精修**补丁。

在官方简体中文的基础上，逐条重译与润色全部文案 —— 全 985 条里改了 **528 条**：船员姓名、职务术语、书页章节与图注、命运描述、对话、帮助提示。人名不再按拼读猜，而是逐个人名对照《新华社世界人名翻译大辞典》等权威资料核对。

安装时可以自己挑组合：**未和谐 / 和谐版**、**双语 / 纯中文**、**中文姓名 / 英文姓名**，中文姓名还能选**旧翻译 / 新翻译（精修）**与**是否缩写**。装完不满意，随时换个组合重装一次即可。

本程序**完全离线**：不联网、不注册、不上传任何东西，只改你自己电脑上的游戏文件。动手前会自动备份，随时能一键还原 —— **包括你原先装过的其他汉化或补丁**。

## 下载

到本仓库的 **Releases** 页面，挑对应平台的压缩包：

| 你的系统 | 下载 |
|---|---|
| Windows 10 / 11（64 位） | `ObraDinnCN-Installer_Windows.zip` |
| macOS（Intel 芯片；Apple 芯片机型经 Rosetta 2 运行） | `ObraDinnCN-Installer_macOS.zip` |

包里就一个程序，没有别的文件：Windows 是 `ObraDinnCN-Installer.exe`（单文件，双击即用），macOS 是 `ObraDinnCN-Installer.app`（拖进「应用程序」文件夹）。**这篇说明就是全部文档。**

---

## 在 Windows 上使用

解压后双击 `ObraDinnCN-Installer.exe`，**不需要安装**。这个 exe 拷到 U 盘或另一台电脑上照样能用。

它是单文件程序：双击后大约要**等 8~10 秒**（这时屏幕上会有一张启动画面），窗口才会出现。

**第一次打开被系统拦下？** 程序没有买代码签名，Windows 可能弹出「Windows 已保护你的电脑」—— 点「更多信息」→「仍要运行」。如果还是不行：右键 exe → 属性 → 勾上底部的「解除锁定」→ 确定。

## 在 macOS 上使用

把 `ObraDinnCN-Installer.app` 拖进「应用程序」。启动是**瞬间**的。

**第一次打开被系统拦下？** 同样因为没有 Apple 开发者签名，任选一种：

1. 在 Finder 里**右键**点它 →「打开」→ 弹窗里再点「打开」（之后就能正常双击了）
2. 系统设置 → 隐私与安全性 → 拉到底部 →「仍要打开」
3. 打开「终端」跑一行：

   ```
   xattr -dr com.apple.quarantine /Applications/ObraDinnCN-Installer.app
   ```

## 精修了什么

全 985 条文案里改了 528 条，分布如下：

| 类别 | 条数 | 例子 |
|---|---|---|
| 对话 | 326 | 语序、称谓、生硬直译的句子 |
| 船员姓名与职务 | 69 | 见下 |
| 命运描述 | 43 | 见下 |
| 帮助与提示 | 31 | 「还有一个人在场」→「另有一个人在场」 |
| 书页：章节名 / 图注 / 前言 | 17 | 「II. 苦寒」→「II. 风寒」、「VII. 劫数」→「VII. 毁灭」 |
| 术语表 | 9 | 全书术语统一 |
| 其他（翻页提示、点名、存包等） | 33 | 「尸体被移动过」→「尸体死后被移动过」 |

### 人名与职务：逐条对照词典

官方简中的人名是**按拼读**转写的，会出现与通行译名对不上、同一个人两种写法、缩写不成形等问题。精修版逐个核对后重新译写，并补上规范的姓名缩写：

| 官方简中 | 精修版（不缩写 / 缩写） |
|---|---|
| 罗伯特·威特瑞（船长） | 罗伯特·威特里尔 / R. 威特里尔 |
| 阿佛雷·克莱斯蒂（水手长） | 阿尔弗雷德·克勒斯蒂尔 / A. 克勒斯蒂尔 |
| 蒂莫西·比门 | 蒂莫西·布特门特 / T. 布特门特 |
| 努兹奥·帕斯夸 | 农西奥·帕斯夸 |
| 克里斯汀·沃尔夫 | 克里斯蒂安·沃尔夫 |
| 爱德华·尼柯斯 | 爱德华·尼科尔斯 |

职务与术语也一并统一，避免同一个词在书里出现两三种写法：

| 官方简中 | 精修版 |
|---|---|
| 炮手 | 枪炮长 |
| 副炮手 | 副枪炮长 |
| 见习船员 | 见习官员 |
| 乘务员 | 服务员 |

（上面每一行都是补丁里的实际改动。）

### 顺带修好的三件事

- **中文里的英文不再被拦腰截断。**「ObraDinn」「well-known」「0.5」这类夹在中文句子里的英文词，官方排版会从中间断开；补丁改掉了这条断行规则，并顺手补上了越界检查。
- **字体更完整。** 书页与正文用到的中文字体换成了字形覆盖更全、显示更清晰的版本。
- **结尾鸣谢里的中文署名**换成了本补丁的作者。

## 安装时要选的五件事

向导一共五步，选完点「安装」，几秒钟就装好了（日志会实时显示在进度页）。

| 步骤 | 选项 | 说明 |
|---|---|---|
| 2 · 是否和谐 | **未和谐（推荐）** / 和谐版 | 和谐版把不易过审的地名相关文字做了处理，适合录制视频或直播 |
| 3 · 是否双语 | **双语显示（推荐）** / 单语 | 双语是中文与英文并列；单语只显示中文 |
| 4 · 姓名样式 | 中文姓名 / 英文姓名 | 中文是「阿尔弗雷德·克勒斯蒂尔」这种写法，英文保留「A. 克勒斯蒂尔」 |
| └ 译文版本 | 旧翻译 / **新翻译（精修）** | 旧翻译和社区里流传的版本一致，方便和人交流；新翻译更准确 |
| └ 姓名缩写 | 不缩写 / 缩写 | 缩写是「A. 克勒斯蒂尔」这种形式 |

选「英文姓名」时不需要选译文版本，缩写则是固定的。

## 常见问题

**会动我的存档吗？**

不会。补丁只改游戏自己的文件（字体、书页文字、语言包、以及中文断行规则），完全不碰存档。

**会改游戏难度吗？**

不会，**难度是只读的**。补丁只读取你当前的难度档位，然后写对应的文案（比如你把难度改成了「一批 58 人」，提示语里就会写「五十八」）。所以它和「Obra Dinn 难度补丁」可以一起用。

**我装过别的汉化或补丁，会冲突吗？**

不会覆盖别人的成果。补丁会在**你现有文件的基础上**工作，动手前把原文件备份一份；随时点「解除安装」就能回到装补丁之前的样子，其他补丁原样保留。

**怎么卸载？**

重新打开这个程序，选**「解除安装」**，它会用安装时的备份把游戏写回去。

**杀毒软件报警了？**

没有签名的免费小程序常被误报，放心加入白名单即可。

**游戏更新了要重装吗？**

游戏更新可能覆盖掉补丁文件，重新安装一次即可（补丁是幂等的，重复安装不会叠加出问题）。

**为什么 20 种搭配都能装？**

补丁按「你选的组合」重新生成语言包，所以任何组合都只是重新生成一次，不会把上一种组合的残留留在游戏里。

**出问题了怎么反馈？**

到本仓库的 **Issues** 里贴一下：游戏装在哪个系统、装了哪个版本、界面上进度页的日志。能看到问题就能修。
